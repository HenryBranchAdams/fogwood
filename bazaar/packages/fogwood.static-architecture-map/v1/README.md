# Architecture Map

Architecture Map is a local, immutable starter that makes the people, agent, page, and local-store boundary visible.

It stages existing Fogwood blocks and native arrows. A person reviews the proposal and chooses Apply or Reject. The package does not execute generated work, write the store directly, or grant page authority.

The included examples and fixtures describe the bounded data shape and the known malformed, oversized, and information-loss cases.
