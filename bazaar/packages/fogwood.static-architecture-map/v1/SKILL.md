## Intent

Choose this package when the local authority boundary needs a compact spatial explanation for a person or an agent reviewer.

## Workflow

1. Inspect the current page revision and exposure policy.
2. Read the pinned package identity and the recipe example.
3. Ask which audience needs the boundary and which part needs emphasis.
4. Stage the immutable recipe against the inspected revision.
5. Explain the human gate, then wait for page-owned Apply or Reject.

## Review checks

- The page remains the state owner.
- The local store remains the persistence owner.
- The agent only stages a bounded proposal.
- Apply and Reject remain visible human choices.

## Prohibited effects
