# Evidence Map

Evidence Map is a local, immutable starter for placing sources, claims, open questions, and a compact review ledger on the Fogwood canvas.

It stages existing Fogwood blocks and native arrows. A person reviews the proposal and chooses Apply or Reject. The package does not retrieve sources, decide whether a claim is true, or send board data anywhere.

The included examples and fixtures describe the expected bounded data shape and the known malformed, oversized, and information-loss cases.
