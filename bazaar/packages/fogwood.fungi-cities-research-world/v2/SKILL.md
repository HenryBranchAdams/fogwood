# Workflow

1. Inspect the live canvas and any human spatial edits.
2. Read this exact local composition and its source notes.
3. Keep observed evidence, analogy, inference, and open questions visibly distinct.
4. Stage the composition for review; stop for page Apply or Reject.
5. After human manipulation, inspect again and branch or annotate the world instead of overwriting it.

The package is data-only. It has no code, fetch, remote embed, provider authority, or automatic image generation.
