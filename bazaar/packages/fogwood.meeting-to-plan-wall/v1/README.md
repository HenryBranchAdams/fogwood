# Meeting Wall

Meeting Wall is a local, immutable starter for turning notes into a decision, risks, actions, owners, and a compact plan ledger.

It stages existing Fogwood blocks and native arrows. A person reviews the proposal and chooses Apply or Reject. The package does not capture audio, assign owners, or send follow-up messages.

The included examples and fixtures describe the bounded data shape and the known malformed, oversized, and information-loss cases.
