# Storyworld mutation map

This immutable `composition.v2` starter gives places, rules, factions, portals, tensions, and scenes room to branch. One preserved variant is linked by a visible `mutates_into` edge; the source branch remains on the page. Shapes are deliberately uneven and editable so a person can move, annotate, or mutate a branch without erasing its lineage.

Stage the map for page review. Apply is a human decision, and later canon is a new proposal rather than an unattended overwrite.
