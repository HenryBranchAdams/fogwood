# Evidence constellation

This immutable `composition.v2` starter uses native shapes arranged as a loose constellation. Claims, sources, counterarguments, and questions are connected by typed `supports`, `contradicts`, and `depends_on` edges. It deliberately contains no table, checklist, metric, chart, or dashboard block.

Inspect the live page, stage the composition for review, and preserve human movement. Later edits should branch, annotate, or mutate the constellation rather than flattening it into a grid.
